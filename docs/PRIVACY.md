# 隐私与数据边界

知意在本机保存工作数据。模型请求的去向由你选择的服务地址决定。

## 数据与文件

默认业务目录是 `%LOCALAPPDATA%\Zhiyi`；指定独立数据目录时使用该目录。任务数据库、托管原件和内部设置保存在这里，导出、原件副本与备份可保存到你指定的位置。普通卸载保留数据；只有明确选择清除才清除托管范围，外部副本、单独备份及模型文件不随应用内清除操作删除。

较大文件可能只把部分内容交给模型，原件仍独立保留。仓库中的来源处理范围和待核对标记是状态提示，不能代表提取准确率。独立导出或合并后的副本不会自动跟随来源任务的后续确认更新。

## 模型与密钥

请求发送到配置的地址。即使方案名称是 LM Studio 或 Ollama，只要填写远程地址，请求也可能离开本机。使用云服务时，相关文档内容、图片、字段和提取提示发送给该服务。服务方的留存、训练用途和数据所在地由其政策决定。

Windows 桌面版模型 API Key 使用系统凭据管理器；模型快照引用密钥记录，完整业务备份不包含密钥明文。恢复备份到另一台机器后可能需要重新填写模型密钥。不要把密钥、业务原件或备份上传到公开问题和仓库。

## API 与 MCP

默认 API 只监听本机。MCP 权限默认关闭，文件导入受许可目录限制；导出同时要求文件访问与数据读取权限。按需开放，权限变化在新连接生效。当前没有组织账户、多租户隔离或公网身份认证。

## 日志与诊断

界面状态摘要与故障详情分开。详情有明确长度上限，过长时保留首尾并提示省略；常见密钥模式和个人路径会脱敏。这不保证能识别任意模型回显或任意格式的隐私信息。分享诊断前仍应检查，尤其不要连同原始业务文件一起公开。

项目本身不会自动把业务数据上传到代码仓库。公开演示和自动验收只使用合成资料，不使用真实用户库。
