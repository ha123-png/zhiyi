# 隐私与数据边界

知意是本地优先应用，但“本地优先”不等于所有模型调用都在本地完成。

## 本地保存

任务数据库、上传文件、模板、设置、导出文件和备份默认保存在当前 Windows 用户目录下。普通卸载保留这些数据；用户在卸载确认中选择彻底删除时才会清除。

## 模型调用

- 使用 LM Studio 或 Ollama 时，模型请求发送到用户配置的本机地址。
- 使用云端 OpenAI-compatible 接口时，文件内容、模板字段和提取提示会发送给对应服务商。
- 项目不会替任何第三方服务商保证数据所在地、留存周期或训练用途，使用前请阅读其隐私政策。

## API 与 MCP

API 默认仅绑定 `127.0.0.1`。MCP 权限默认全部关闭，用户按需开放。项目当前不包含组织账户、多租户隔离或公网身份认证，不应直接暴露到公网。

## 日志与诊断

诊断功能应避免导出 API Key、完整模型响应和业务文件内容。提交 Issue 前仍请人工检查诊断文件并删除敏感信息。
