# 知意 v0.5.0

知意 v0.5.0 面向 Windows x64。此版本重新整理了文件当前数据和修订历史的底层模型，让文件详情、数据仓库、仪表盘、问知意、导出与接口读取同一份当前事实。

**原件是证据，当前数据是事实，修订历史解释变化。**模型负责理解文件，程序负责确定性校验和执行；模型输出仍需按实际业务核对。

## 本版变化

- **文件只有一份当前事实。** `file_current_data` 保存每个文件的当前文件级字段、结构、校验状态和并发版本，`data_rows` 保存当前明细。文件详情与数据仓库共享这些值；不再把提取结果快照当作另一份当前数据。
- **修订按文件版本记录。** 文件详情的一轮编辑形成一个文件版本；仓库编辑及时保存，并按编辑会话整理文件修订。修订保留字段前后值以及新增、修改和删除的明细；旧提取、核对记录仍是原始来源证据。
- **模板不再决定事实表的生存。** 模板描述字段、理解要求与规则。模板版本更新不拆散目标表；修改或删除模板不会删除既有业务数据。
- **自主提取保留每份文件自己的结构。** 每份文件可以有不同字段，按文件阅读和导出。相同字段名称不代表相同口径，不会自动拼成统一数据表。
- **整理、统计与受控问答共用事实。** 数据仓库提供表格与卡片、筛选、搜索、导入、合并、动态分组及导出；仪表盘由程序计算统计；问知意在授权范围内查询和提出受控修改，修改先预览再确认。
- **更清楚地区分清理范围。** 清除当前数据会保留原件和修订；删除整个文件会移除该文件当前数据、内部原件及直属历史。独立导入或合并结果不会因为来源文件删除而被回写或撤销。
- **界面反馈围绕当前事实收敛。** 文件卡片、原件预览、文件历史和数据仓库沿用知意已有的交互样式；并发编辑冲突会刷新到最新值，未保存输入与已保存事实分开展示。
- **问知意操作受授权和时效约束。** 读取和修改遵守当前资料范围；数据修改先预览再确认。授权、范围或数据发生变化后，旧预览会过期，重新授权不会让它复活。
- **原件与恢复流程增加完整性保护。** 受管路径和归档目标会校验；删除失败保留可重试的清理义务。业务备份逐项检查内部原件，恢复先在暂存区校验数据库和文件；暂存迁移失败时活动数据不被替换。

## 数据迁移与兼容

v0.5.0 支持从 v0.4.0 Beta 自动迁移**能无歧义形成唯一当前事实**的数据。迁移会将原有文件结果与仓库明细归并到新的当前数据结构，保留可对应的原始记录与明细身份，并为文件修订建立迁移基线。迁移前程序会在数据目录 `backups` 中创建 SQLite 数据库副本。

v0.4.0 允许文件侧和仓库侧分别修改，因此某些旧记录可能存在不同的当前值。若迁移发现旧值不一致、字段归属无法确认或无法判断文件当前数据是否被有意清空，就会停止，不替用户选值或丢弃其中一份。此类记录需保留旧工作区和完整备份；继续使用 v0.5.0 时，应在独立的新工作区重新导入原始文件并核对业务值。v0.5.0 不提供将有冲突的旧库原地合并或人工选择其一的流程。

数据库结构与备份不是跨版本可互换格式：v0.4.0 不能直接读取或写入已经迁移的 v0.5.0 数据库；v0.5.0 修订结构不能在原地降级。要回到 v0.4.0，需使用升级前由 v0.4.0 创建的完整业务备份和对应旧程序。升级前请另行制作完整业务备份；迁移自动创建的 SQLite 副本不包含内部原件，不能代替完整备份。完整备份也不包含外部归档/副本、模型文件或 Windows 凭据管理器中的 API Key。

具体步骤见[升级使用说明](../升级使用说明.md)。

## 已知边界

- 提取结果取决于文件质量、读取范围、模型能力和硬件；复杂布局、扫描识别和逐字段精确定位不能保证。重要业务数据应对照原件人工核验。
- 云端模型请求会将相关文件内容发送给配置的服务商；服务商的数据处理政策由服务商决定。
- 产品面向本机单用户场景，不是多用户组织系统或 ERP 自动入账工具。
- 当前发行包为 Windows x64，未进行 Authenticode 代码签名；请从官方 Release 获取并核对 SHA-256。
