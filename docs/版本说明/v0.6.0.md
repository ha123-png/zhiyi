# 知意 v0.6.0

知意 v0.6.0 是 Windows x64 公开 Beta。本版修复第二轮外部审计提出的 43 项问题，重点改善复杂数据操作、模型凭据隔离、异常中断恢复和编辑状态反馈。安装包未进行 Authenticode 代码签名，请从官方 Release 获取并核对 SHA-256。

## 主要变化

- **导入和导出更可预期。** 修正短行、表头映射、内部列和搜索范围处理。无缓存公式、超限 CSV/XLSX 等无法忠实读取的内容会明确报错，不会静默变空、截短或被覆盖。
- **大数值保持精确。** 超出 JavaScript 安全整数范围的值通过界面 API 以十进制字符串传递；数值编辑拒绝可能造成精度损失的写法，并在校验失败时保留未保存草稿。Excel 无法无损保存的数值会提示改用 JSON。
- **编辑过程受到保护。** 文件核对和历史原件对照在离开或切换前保护未保存输入。校验规则的忽略或恢复会留下文件版本记录；过期请求、并发保存和动态分组变化不会悄悄改写当前选择或状态。
- **模型密钥按服务隔离。** 已保存的 API Key 只绑定相同服务类型和规范化后的服务地址。切换到其他服务或地址时，空白密钥不会继承旧服务的凭据；旧版本和已创建任务仍可使用其原有凭据引用。
- **中断后更好恢复。** 上传在文件落盘与任务登记之间遇到进程中断时，会通过持久标记检查并恢复；无法确认归属的原件会保留。备份恢复期间若清理失败，可恢复副本及其状态说明仍会保留。
- **统计、助手和页面加载改进。** 统一统计时间边界和时区处理；助手会话进度可以持久化并在异常退出后恢复。8 个次级页面改为按需加载，主入口构建产物约减少 23%；页面加载失败时提供重试入口。

## 升级与数据兼容

v0.6.0 沿用 v0.5.0 的当前数据和修订结构，没有新增数据库迁移。已使用 v0.5.0 的 Windows 安装可直接更新；升级前仍建议在“备份”页创建并另存完整业务备份。

从 v0.4.0 升级时，仍适用 v0.5.0 的迁移规则：结构明确且各处旧值一致的数据可以迁移；存在冲突或无法确认归属的数据会阻止迁移，不会由程序擅自选择一边。完整边界与处理步骤见[升级使用说明](../升级使用说明.md)和[v0.5.0 版本说明](v0.5.0.md)。

## 使用边界

本版修复聚焦软件安全、数据完整性和工作流反馈，不表示不同模型的广泛准确率已通过评测。模型输出仍可能有误；重要数据请对照原件人工核验。云端模型会收到本次请求涉及的文件内容，请根据服务商的数据政策选择使用方式。
