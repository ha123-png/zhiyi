# 知意 v0.7.0

本版更新文件提取、数据仓库、对外接口和 Windows 安装更新。已发布的安装包及摘要见[发行页](https://github.com/ha123-png/zhiyi/releases)。

## 文件提取与任务

- 状态监控统一显示进行中、已完成、待确认、失败与已取消任务。顶栏的待处理总数包含重复文件，点开可处理具体事项。
- 重复文件确认可跨页和重启保留。平台已有对应原件时，可查看已有结果、再次提取或跳过。批量删除只需确认一次。
- 可暂停整条队列，也可只暂停指定文件。单文件失败后队列继续处理其他文件。失败或取消的文件可重试。
- 智能匹配只使用匹配范围中勾选的普通模板。自主提取可作为找不到适用普通模板时的兜底。类型不符的值可逐项对照原件核对。文件级字段与明细按分区独立校验。

## 数据仓库、模型与接口

- 合并表实时读取关联原表，按原表顺序展示。编辑或追加到原表后，合并表更新。旧独立合并结果仍可作为普通表读取。
- 普通 Excel 导出业务字段和明细。附加资料可以导出整表修订历史与提取范围。修订目录按任务跳转到工作表，每个版本用标题和空行区分。Excel 导入读取文件内已保存的公式结果。
- 本地模型管理分别显示下次加载的上下文长度与当前容量。问知意的自动预算可读取服务报告的已加载上下文。操作预览、统计与编辑冲突的处理延续现有数据授权和版本保护。
- HTTP API 提供读、写密钥。重新生成的读密钥可查询任务、表格与结果，并下载原件和读取修订历史。写密钥也可上传及修改数据行。原有密钥继续沿用已授予的权限。MCP 按能力独立授权。 [API 与 MCP](../开发/API与MCP授权边界.md)

## 升级

- 合并表关联由数据库迁移 `0047_live_table_merge` 建立。旧版的独立合并结果保留，可按需从原表重新创建实时合并表。
- Windows 版在「设置 → 关于知意」检查、下载并校验可用更新。选择「重启并更新」后，会在安装前备份业务数据并保留旧程序。手动覆盖升级和回退步骤见[升级使用说明](../升级使用说明.md)。
