# 知意 v0.7.0

相对 v0.6.0，本版改进任务处理、文件提取、数据仓库、问知意和对外接口，并增加 Windows 应用内更新。 [安装包与校验值](https://github.com/ha123-png/zhiyi/releases/tag/v0.7.0)

## 文件提取与任务

- 状态监控统一显示进行中、已完成、待确认、失败与已取消任务。顶栏的待处理总数包含重复文件，点开可处理具体事项。
- 重复文件确认可跨页和重启保留。平台已有对应原件时，可查看已有结果、跳过，或用该原件新建再次提取的任务。状态监控和文件历史采用一致的删除确认，批量删除只确认一次。
- 可暂停整条队列，也可只暂停指定文件。单文件失败后队列继续处理其他文件。失败或取消的文件可重试。
- 智能匹配只使用匹配范围中勾选的普通模板。自主提取可作为找不到适用普通模板时的兜底。
- 自主提取会分别校验文件级和明细字段，支持分区同名与文本字段接收纯数字。待核对问题按字段列出原值及类型要求。诊断能区分 JSON 解析失败与字段结构错误。
- 文件提取和问知意显示实际读取范围。Office 文件在本机解析后发送相关文字和支持的图片，原件保留用于核对。后台任务完成时保留当前核对草稿和焦点。

## 数据仓库、模型与接口

- 合并表实时读取关联原表，按原表顺序展示。编辑或追加到原表后，合并表更新。旧独立合并结果仍可作为普通表读取。
- 普通 Excel 导出业务字段和明细。附加资料可以导出整表修订历史与提取范围。修订目录按任务跳转到工作表，每个版本用标题和空行区分。Excel 导入读取文件内已保存的公式结果。
- 本地模型管理分别显示下次加载的上下文长度与当前容量。问知意的自动预算可读取服务报告的已加载上下文。操作预览、统计与编辑冲突的处理延续现有数据授权和版本保护。
- HTTP API 提供读、写密钥。重新生成的读密钥可查询任务、表格与结果，并下载原件和读取修订历史。写密钥也可上传及修改数据行。原有密钥继续沿用已授予的权限。MCP 按能力独立授权。 [API 与 MCP](../开发/API与MCP授权边界.md)
- 仓库提供可编辑的空工作区示例。卡片和表格支持跳页，按内容分组，宽窗口的卡片一行最多三张。支持直接编辑来源字段，刷新与写入冲突时保护尚未提交的内容。
- 问知意的统计回答引用本轮实际完成的统计。操作计划按授权范围校验，过期操作保留原因。修复断开、重连、停止回答和切换会话时的迟到状态。
- 应用内「使用说明」与问知意共用同一份手册，补充文件格式、输入覆盖、备份还原、暂停层级，以及 HTTP API 和 MCP 的访问边界。

## 界面与数据可靠性

- 精简页面标题和重复任务提示，将常见处理事项放到状态监控。文件提取、仓库和备份使用短反馈或弹窗，保留表格布局。统一细线折叠箭头，并尊重系统减少动态效果设置。
- 改进设置和模板页的草稿保存。模板编辑保留示例字段和版本，多份 PDF 样例分别处理。增强小窗口、键盘焦点、原件对照和页内滚动。
- 数值读入与校验保留原始精度。规则运算更新为 `template-v3`，现存历史继续保留原版本。Excel 预览区分数据工作表与图表页，对不支持的数字精度和结构给出提示。
- 备份页支持复制完整路径和打开备份目录。需要提取备份内部文件时，可使用通用 ZIP 工具打开备份副本。修正重复启动端口、关闭与恢复请求交错等问题。

## 升级

- 合并表关联由数据库迁移 `0047_live_table_merge` 建立。旧版的独立合并结果保留，可按需从原表重新创建实时合并表。
- Windows 版在「设置 → 关于知意」检查、下载并校验可用更新。选择「重启并更新」后，会在安装前备份业务数据并保留旧程序。手动覆盖升级和回退步骤见[升级使用说明](../升级使用说明.md)。
- Windows x64 安装包未进行 Authenticode 代码签名。首次覆盖旧版时建议先备份，并核对发行页提供的 SHA-256。提取效果取决于模型、原件和读取范围。
