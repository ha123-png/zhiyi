# v0.4.0 最终交互收尾验证

2026-09-15。接续《0.4.0规模稳定性与交付验证》，本轮只处理验收返回的五项问题。

| 用户看到的问题 | 本轮结果 |
| --- | --- |
| 没有配置币种却反复警告“未记录币种” | 取消这一默认提示。已有明确币种字段且出现混币时，仍拒绝混算。历史模型写出的正文保持原样，结构化结果中的旧默认提示不再展示。 |
| 有意义的文字说明被折叠 | 正文直接展示，包括长说明；仅重复的查阅与准备过程折叠。 |

| “重新分析”把整段 JSON 交给小模型，导致统计口径变形 | 按钮直接调用本地统计程序，使用已保存的原查询，追加新快照与更新时间。无模型调用、无原始表内容外发，旧快照不改写。范围缩小、字段删除、对话归档或仍在生成时明确阻止；重复网络请求不会生成重复结果。 |
| 柱线图的“记录数”与最高刻度 1000 重叠 | 将轴标题移到绘图区上方，普通卡片和展开图均复核，标签与刻度间距约 9 像素。 |

- 后端完整回归：731 项通过；前端：39 个文件、166 项通过。消息操作收尾后另跑 17 项问知意测试通过。

- 1000 / 10000 条数据：更改一条金额后重算，完整合计正确、结果仅含 10 个分组，无关长文本不进入结果。
