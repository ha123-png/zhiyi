# 从安装到第一份数据

## 1. 安装并打开

运行 Windows 安装包，安装完成后打开桌面的“知意”。升级前建议在“备份”页做一次完整备份。默认卸载只移除程序；只有明确选择同时删除数据才会清除本地业务资料。

如果系统提示无法确认发布者，说明安装包目前没有可信发行签名；请先核对来源与发行包提供的 SHA-256 摘要，不关闭系统安全防护。正式下载位置由发布说明给出。

## 2. 连接模型

进入模型配置。已有云服务时，填写对应接口地址、模型名称和自己的 API Key；使用本地服务时，先在 LM Studio 或 Ollama 准备好合适的模型，再连接知意。模型服务和模型文件不包含在知意安装包内。

本地服务的“启动”按钮不能代替首次安装或下载模型。未安装时，按界面提示安装/打开对应程序。图片或扫描件需要模型支持视觉输入；文字接口能用不代表图片识别也合格。

选择云模型会发送与本次请求有关的文档内容。密钥只填写在自己的设置中，不放进模板、截图或反馈材料。

## 3. 先做一份简单模板

以“活动物资清单”为例：记录标题作为表头；物资名称、数量、备注作为明细列。把数量类型设为数字。确实必需的字段再设为必填。

也可以让 AI 根据你的要求起草；生成后检查字段和建议规则。不要把“多数时候如此”误设成强制规则。使用正则格式约束时，界面中的试填会按实际校验方式检查整段输入，复杂语法请以界面提示为准。

## 4. 上传、核对、确认

先上传一份小文件并指定模板。完成后对照原件检查：字段是否对应，明细是否漏行，同名记录是否被混在一起，缺失值是否处理得合适。

如果提示只处理了部分内容，先阅读处理范围，再决定结果是否足够。原件仍可下载，不要把模型看到的节选当成完整文件。

结果会出现在数据仓库；若有待核对提示，请先回到来源任务处理。没有待处理事项时，任务会自动完成。到数据仓库查找结果。尝试打开来源、搜索一条记录、导出一次，再处理下一批。

## 5. 出错时先看什么

| 现象 | 下一步 |
|---|---|
| 本地服务未安装或未启动 | 先打开对应模型软件，检查模型是否已加载 |
| 模型连接失败 | 核对服务状态、模型名和接口配置；不要反复上传同一文件 |
| 任务失败、提示太短 | 打开任务错误详情；超长详情会明确说明省略，并保留首尾 |
| 规则不通过 | 对照原件和规则说明，修正内容或不合理的规则 |
| 导出目录不可用 | 检查目标磁盘/目录，另选可写位置；内部原件不因此丢失 |

反馈问题时优先使用诊断功能生成的脱敏信息；分享前仍检查是否包含业务内容。不要公开完整业务备份、原件或密钥。

## 以后再开启的能力

API/MCP 适合接入现有自动化工具。只开启所需能力和目录；导出表格同时需要读取数据与文件访问权限。外部工具的事实修改受版本检查约束，过期写入会被拒绝。

知意暂不提供手机 App。Windows 本地使用、可复用模板、核对与导出是当前的主要路径。
