# 知意 v0.4.0 升级使用说明

适用于 Windows x64 的 v0.4.0 Beta，发布于 2026-09-15。完整页面能力见[功能说明](功能说明.md)，首次使用见[快速开始](QUICK_START.md)。

## 从 0.3.0 升级

1. 在旧版的“备份”页创建完整业务备份，保存在安装目录之外。备份包含业务数据和内部原件，模型软件、模型文件与密钥需另行保留。
2. 退出知意。从[本仓库 Release](https://github.com/ha123-png/zhiyi/releases/tag/v0.4.0) 下载 `Zhiyi-0.4.0-win-x64-setup.exe`，可与 `SHA256SUMS.txt` 核对摘要。
3. 安装到原程序目录，无需先卸载。安装器只处理该目录的知意实例，不关闭其他安装目录的实例。
4. 启动新版。数据库自动依次迁移到 `0039_original_archive`，保留已有模板、任务、数据、修订记录及内部原件；旧任务继续保留其模板、模型和读取范围快照。

默认业务目录是 `%LOCALAPPDATA%\Zhiyi`。普通卸载保留业务数据；选择删除数据才会清除。遇到迁移失败请保留原数据库和错误信息，不要通过删库重建解决。回退时需使用升级前备份和对应旧程序，不能直接用旧程序写入新版数据库。

本版未进行 Authenticode 签名，可能出现未知发布者提示。请核对官方仓库与摘要，无需关闭系统安全防护。安装包不包含模型与 API 额度。

## 升级后哪些行为会变化

| 项目 | v0.4.0 的行为 |
| --- | --- |
| 原有模板与结果 | 无需重建，不自动重新提取，也不自动通过待核对问题。 |
| 智能匹配 | 已有选择保留；新建或复制模板默认不参与。准备好后勾选，若副本用于替代内置模板，同时取消内置模板。 |
| 文件名称 | 已开启命名的旧模板保持 AI 模式；可改用“导入日期_模板名_序号”。新任务自动采用名称，原上传名可查，重试沿用名称；旧文件和已有外部文件不批量改名。 |
| 原文件处理 | 原有副本设置继续复制，未启用的继续关闭。移动归档需要在模板高级设置主动选择并保存。 |
| 校验与待处理 | 校验问题会同时出现在文件历史和状态监控；未完成归档留在待处理，完成或跳过后进入最近完成。 |
| 云端上下文 | 旧版远端方案中隐含的 8192 改为自动预算，云端不继承本地加载容量；旧任务快照保持原值。 |
| 对话与统计 | 可独立选择聊天模型，打开历史恢复该对话的模型与资料范围；“按最新数据重新分析”在本机复用原查询，保留旧快照，不调用模型。 |

旧版没有记录 8192 是默认值还是用户主动填写，因此无法完全区分。若希望继续限制远端预算为 8192，请在新版模型方案高级设置中明确填写并保存。新版主动填写的数值不会随自动预算变化。本地方案预算仍应与实际加载容量一致。

## 选择文件命名方式

在模板高级设置开启“文件命名”，从两种方式中选择一种：

- **AI 命名：** 同次提取根据内容建议名称，可在额外提示词中表达命名偏好。缺少可用建议时尝试从已提取字段生成，仍无依据则保留原名；自然语言要求不保证被模型完全遵守。
- **固定规则：** 使用“导入日期_模板名_序号”，例如 `2026-09-15_发票_001.jpg`。不调用 AI 起名，同日同模板递增，重试不重新编号。

两种方式都自动采用，仍可编辑。内部原件与上传原名保留；已归档或已导出的外部文件不随之后的名称编辑自动改名。模板 JSON 可分享命名方式，不携带本机绝对路径。

## 使用原文件归档

在模板高级设置的“原文件处理”中选择“原文件归档”，选择位置并保存。这个选择就是授权，没有第二个确认框。之后通过桌面版“选择文件”导入，提取结果保存成功后，知意将原位置文件移到“所选位置 / 模板名”文件夹，使用最终文件名。

知意先完整写入、校验目标，再移除原位置文件，始终不覆盖同名文件。内部原件继续保留，供预览、重新提取与备份；这不会形成另一份外部副本。

如果同名、占用、权限不足或原文件已经变化，任务进入“待处理事项”。点击“处理”可改名、换位置、重试或跳过，不重新调用模型。目标已写出但原位置移除失败时，保留文件，重试核对并复用已写出的目标；跨盘操作无法成为单个磁盘原子事务，程序通过阶段记录恢复中断。

第一版移动归档适用于 Windows 本机固定磁盘的普通文件。浏览器上传、拖入和粘贴无法提供可核实的原路径；网络位置、链接和云盘占位文件仍可提取，但不能移动归档。需要归档时请用桌面版“选择文件”。知意不会扫描整块磁盘、自动提权或调整目录权限。

只想保留原位置时可选择“复制原件副本”，不需要外部文件处理时选择“不额外处理”。归档、副本与结构化表格导出是不同用途。

## 仪表盘和问知意

仪表盘支持全部时间与最多四张业务统计，保存的统计按当前数据刷新，不调用模型。问知意可以在全部资料或指定范围内查找、统计、绘图与对照原件，修改前统一预览，过期方案不能覆盖新修改。

千条或万条数据不会整表交给模型：明细默认最多三条，长字段有长度限制，后续按需读取；统计由本机程序对完整授权范围计算。历史对话分页加载，完整内容保存在本机，接近上下文预算时整理摘要并按需回读。默认不展示模型内部 reasoning，文字说明直接显示。

提取、对话可能使用不同模型；检查对话设置中的当前选择。选择云端服务时，相关问题、必要历史与授权资料会发送给该服务商。模型仍可能理解错问题，核对实际筛选条件、数据来源和修改预览。

## 备份、恢复与外部文件

完整业务备份包括内部原件和业务记录，不包含外部归档文件、副本、模型文件或密钥。恢复后关闭本机自动文件处理，并清除备份中原文件的移动权限，不继续移动或删除旧路径文件；需要归档时重新选择文件导入。外部文件由你管理，知意不跟踪其后续移动和改名。

对较大文件，上传限制、发送给模型的范围、模型上下文和原件预览范围是不同概念。局部读取有明确标记，原件仍完整保存；范围和待核对状态随支持的 Excel、CSV、JSON 导出保留。详细边界见[功能说明](功能说明.md)与[隐私说明](PRIVACY.md)。
