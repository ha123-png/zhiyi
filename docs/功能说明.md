# 知意 v0.5.0 功能说明

知意把非结构化文件变成可核对、可追溯、可继续使用的结构化数据。模板定义理解要求，模型负责提取，程序校验与人工核对负责把关。表格、卡片、图表和接口使用同一份业务事实。

从旧版本迁移请先阅读[升级使用说明](升级使用说明.md)。

## 第一次使用

1. 在设置中连接本地或云端模型。图片和扫描件需要视觉能力；本地服务还需要实际加载模型。
2. 选择示例模板，或到模板页按需求创建。临时、混合文件可直接选择“自主提取”；固定业务可让 AI 结合样例起草模板，再核对字段和规则。
3. 上传文件，指定模板或使用智能匹配。匹配拿不准、读取范围需要决定时，到状态监控继续处理。
4. 检查提取结果与原件。有校验问题的文件同时出现在状态监控的待处理事项和文件历史的校验问题中。
5. 在数据仓库搜索、编辑、阅读、汇总和导出。入表不等于已经人工核验，来源状态会继续保留。

## 各页面解决什么问题

| 页面 | 主要用途 |
| --- | --- |
| 状态监控 | 查看活动任务、待选模板、待核对、原文件归档及副本问题与失败任务；继续、重试或处理当前页事项 |
| 数据仪表盘 | 查看当前积累、期间变化、模型用量与自定义业务统计；直接前往需复核文件 |
| 文件提取 | 放入文件、选择模板与模型方案，对照原件编辑当前数据；“修订到表”提交一轮修改 |
| 数据仓库 | 使用同一份事实切换表格或卡片；筛选、修改、分组、导入、合并与导出 |
| 文件历史 | 查找已处理文件与校验问题，查看提取过程、读取范围、内部原件、归档和外部副本状态 |
| 模板 | 定义字段、理解要求、校验规则、默认展示与可选命名；AI 起草、复制、分享和版本恢复 |
| 问知意 | 在授权资料内查找、统计、绘图、解释依据，预览并执行数据与任务操作 |
| 备份 | 导出和恢复业务数据、内部原件；升级或迁移前保留可恢复副本 |
| 接口 | 按需开启 API/MCP 的查询、修改、任务控制与限定目录文件访问 |
| 设置 | 管理模型方案、读取范围、本机服务及应用偏好 |

## 一份当前数据，两个编辑入口

原文件是原始证据；当前数据是唯一事实；文件级修订历史解释当前值如何变化。文件详情和数据仓库共享当前数据，仪表盘、问知意、导出及 API/MCP 也从这里读取。

正常提取后数据已经属于该文件，不需要再“保存到表”。在文件详情或原件对照中，多个字段与明细修改、删除可一起通过“修订到表”提交，形成一个文件版本。修订入口旁可以打开历史。

仓库修改及时落盘，不等待关闭页面；同一轮编辑对 A 文件改五处、B 文件改两处，分别形成 A、B 各一个版本。离开仓库、切换主页面或正常退出会结束本轮；异常退出后，已保存的修改不会丢失，下次启动会整理未结束的修订。

文件版本内区分文件级变化与明细变化：共享客户或日期只记录一次；明细删除保留删除前完整内容。历史版本不提供删除入口。旧版核对与逐行记录在“升级前记录”中保留原范围，不冒充新版文件版本。

| 删除对象 | 影响 |
| --- | --- |
| 一条明细 | 当前数据中移除，两处工作视图与后续统计同时不再使用；历史保留删除前内容 |
| 最后一条明细 / 清空此文件数据 | 文件当前数据变空，文件级字段一并清空；原件、文件历史与修订保留 |
| 数据表 | 清除表及其当前数据；有来源文件的原件和文件历史保留，独立表自身的行历史随表删除 |
| 整个文件 | 删除文件记录、内部原件、当前数据与直属修订；已独立合并的结果和外部归档文件不随之删除 |
| 模板 | 从可用规则中移除；保留事实表、数据和旧文件所需的规则快照 |

## 模板、合并与文件卡片

模板版本更新继续写入同一个绑定表，不因修改提示词而拆表。名称和字段顺序改变当前展示；规则改变影响后续任务，旧文件仍使用当时规则。字段 key 是稳定身份，日常操作使用名称；改名不换身份或换算数值。模板停止提取某字段，会保留表中已有列和值；在表中删除列则必须整列没有有效值，零和假值也算有效值，并检查现有依赖。

发票、送货单只是普通示例，可以编辑、停用、删除，删除后不自动恢复。独立导入或合并的表使用自己的字段顺序，不跟随原模板变化。合并 C 是当时 A/B 数据的独立副本，修改 C 不回写 A/B，之后 A/B 追加也不自动追加到 C；冲突字段不能凭同名强行合并。分组则是原表的动态工作视图，不复制事实，新类别随数据出现。

所有真实文件都以一文件一卡呈现，独立导入组和手工数据保持自己的来源身份。文件名作标题，文件级字段分行，明细可展开并分页读取。列表和详情分别分页；单文件千条明细不会拆成千张外层卡片。筛选只命中部分明细时，不能借整卡选择或清空扩大范围。

“自主提取”是模板页的特殊内置模板：不预设字段和固定字段规则，可配置额外要求、命名和归档。每份文件独立确定结构，提取结果仍可修订。默认不加入智能匹配；主动加入后，仅在没有适用普通模板时兜底，接口失败不会冒充无匹配。任务采用提交时冻结的选择范围。

自主提取只提供文件卡片，不提供跨文件统一列或参与合并；相同字段名称不代表相同口径。Excel 一文件一 Sheet，超过一百份按工作簿分包并保留目录；JSON 保留完整文件结构。不提供强拼为统一 CSV 的出口，其阅读型 Excel 也不能作为普通平面表无损导回。

普通导出遵守当前分组、搜索及选择范围；空选择不会变成整表。Excel 导入遇到多个业务 Sheet 时先选一个，不静默导入活动页。独立数据历史包含已删除行，可从数据表操作菜单打开。

## 仪表盘、问知意与文件处理

**仪表盘。** 当前存量和所选期间的变化分开计算，支持“全部”时间范围。最多保留四张简单统计，可选记录数、合计、平均值，按类别或日期分组。保存后按当前数据刷新，不调用模型。问知意中符合条件的分析可预览后加入仪表盘。图表支持短促过渡、键盘查看和数据明细，遵循系统减少动态效果设置。

**问知意。** 提取与对话可以使用不同模型。打开历史对话时恢复该对话使用的模型和资料范围；设置中显示下一条消息使用的模型。可选择全部资料或指定表、文件、模板与记录范围，统计数值由程序计算；文件总额不会因多条明细重复相加。资料明确记录了不同币种时不混算，缺失值不充当零。图表保存当时的快照，“按最新数据重新分析”直接在本机复用原统计口径，追加带更新时间的新结果，不调用模型，也不覆盖旧结果。当前授权范围若与原统计口径不兼容，会明确提示。

同一意图的修改合并成一个预览，列出对象和变更前后。默认确认后执行；取消、已执行、过期、被新方案替代和撤销都有对应状态。记录已经变化时会拒绝旧预览，避免覆盖后续修改。“本次委托”仅执行授权内可支持的操作，不开放备份、密钥或操作系统控制。

模板的创建、修改和恢复统一在模板页；问知意可以解释模板，不能替代模板页的样例上传与规则编辑。

使用说明与问知意共享知识手册，按主题读取；手册不会全量塞进系统提示。问知意可按授权范围读取当前数据、文件版本和升级前记录，目录和具体变化分别分页；只选几条明细不等于允许查看整份文件历史。自主提取按文件阅读和比较，不把同名异构字段自动汇总。

**文件命名。** 开启后可二选一：AI 根据内容建议名称，或固定使用“导入日期_模板名_序号”，例如 `2026-09-14_发票_001.jpg`。AI 模式可在额外要求中表达命名偏好，旧模板继续使用 AI 模式；固定模式不请求 AI 起名，同日同模板序号递增，重试沿用已分配名称。名称随提取自动生效，仍可编辑。原上传名和内部原件保留，已导出的外部副本不会被回头改名。

**原文件归档。** 模板高级设置中的“原文件处理”可选择“不额外处理”“原文件归档”或“复制原件副本”。选择归档并保存模板即生效，不再二次确认。通过桌面版“选择文件”导入，提取结果保存成功后，知意将原位置的文件移动到“所选位置 / 模板名”，使用最终文件名；内部原件继续保留，供预览、重新提取和备份。归档未完成的任务留在待处理事项，完成或跳过后才进入最近完成。旧版复制设置保持复制，不因升级自动改为移动。

归档先完整写入并校验目标，再移除原位置的文件；不覆盖同名文件。冲突时可在“处理”弹窗改名、换路径、重试或跳过，不重新调用模型。如果目标已写出而原文件仍被占用，保留文件并等待重试，不再次生成副本。导入后已变化的原文件不会被移动或删除。第一版移动归档支持 Windows 本机固定磁盘的普通文件；网络位置、链接和云盘占位文件仍可提取，但不能移动归档。浏览器上传、拖入或粘贴文件不提供可核实的原路径，请用桌面版“选择文件”完成需要归档的导入。

**界面减负。** 状态监控的四个列表保持固定高度，更多任务在列表内滚动。长文件名省略显示，悬浮可看全名，不挤压标签和按钮；归档或副本冲突通过“处理”弹窗改名、换路径、重试或跳过。问知意优先显示最终图表，重复的准备过程可展开查看，文字说明直接呈现；宽表横向滚动，日期和数字保持完整。柱线组合图的轴名称与数值刻度分开显示。

**匹配范围。** 新建和复制的模板默认不参与智能匹配。准备好后，在提取页明确勾选；如果副本用于替代内置模板，同步取消内置模板即可，避免两份相似模板竞争。已有匹配选择保留。

**编辑与反馈。** 模板字段、名称、用途及本机原文件处理设置有未保存编辑时，切换模板或离开页面会提示。按钮悬浮只反馈当前按钮，选中状态清晰但克制；操作确认使用框体，展开与收起有过渡。

## 云端上下文、历史与 reasoning

“上下文预算”在模型方案的高级设置中可见、可修改，它控制知意的请求预算，不是本地模型的加载控件。留空采用自动预算：已知的阿里云 Qwen 3.6 Flash 为 1,000,000 Token；未知远端采用可修改的 32,768，本机默认 8,192。本地预算应与实际加载容量一致，远端预算应与服务的实际能力一致。

旧版远端方案隐含的 8192 会转为自动预算，原数值和旧任务快照保留。旧版未记录数值是界面默认还是接口主动填写，因此无法完美识别旧接口用户手填的 8192；需要继续限制为该值时，可在新版明确填入并保存。新版主动填写的预算保持固定，不随自动推荐变化。

表中有 1000 条或 10000 条记录，也不会整表塞入对话。模型默认得到最多 3 条明细或分组预览，长字段受长度限制；可以指定字段、筛选、排序并按需续读。统计由后端对完整授权范围计算，不把三条预览当作总体。图表引用完整分析快照。

完整对话保存在本机；打开时分页加载最近消息，更早的对话可搜索、翻页或按需回读。知意复用相同方案、相同范围且未变更的原生对话片段；范围、方案或操作状态变化后重建有关上下文。接近预算时压缩历史与工具摘要，完整资料不丢弃。文字通过增量事件直接显示，断线可续传；停止或重启后保留已保存内容，不反复加载整段回答。

云端使用稳定提示前缀，并记录服务实际上报的缓存命中；不承诺每次命中。默认请求关闭 reasoning，服务仍可能自行返回推理片段；内部推理不作为正文展示，用量按服务上报记录。提取正确性、工具执行和数据修改不依赖模型自述。

## 文件、导出与备份的边界

支持 PDF、DOCX、XLSX、常见图片及 TXT/Markdown；复杂版式与嵌入内容的支持有限，完整原件始终可单独下载。上传大小、发送范围、模型上下文与预览范围是不同限制，界面会说明对应阶段。

待核对来源和局部读取信息随支持的 Excel、CSV、JSON 导出保留，包括 MCP 导出。表头与业务文本不会被当作 Excel 公式执行；业务表名包含 `/` 等字符时，导出工作表名会安全转换。

完整备份同时保留业务记录与内部原件。单个备份最多十万个原件，未压缩成员总量上限 100 GiB；磁盘空间不足、清单不完整或校验和不一致时会明确拒绝。外部归档、副本、模型文件和模型密钥不随业务备份搬迁。恢复后关闭本机自动文件处理设置，并清除原文件移动权限，不会继续删除旧路径中的文件；需要归档时重新选择文件导入。模型连接仍需核对。

当前仍以 Windows 本地使用为主。大表统计最多接受筛选后的十万行，超出会要求缩小范围，不返回冒充全量的截断结果。模型可能理解错问题，检查实际筛选、数值来源和操作预览，仍是使用流程的一部分。
