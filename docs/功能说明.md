# 知意 v0.4.0 功能说明

知意把非结构化文件变成可核对、可追溯、可继续使用的结构化数据。模板定义理解要求，模型负责提取，程序校验与人工核对负责把关。表格、卡片、图表和接口使用同一份业务事实。

## 第一次使用

1. 在设置中连接本地或云端模型。图片和扫描件需要视觉能力；本地服务还需要实际加载模型。
2. 选择内置模板，或到模板页按需求创建。AI 生成支持需求描述与样例文件，字段和规则由你核对后保存。
3. 上传文件，指定模板或使用智能匹配。匹配拿不准、读取范围需要决定时，到状态监控继续处理。
4. 检查提取结果与原件。有校验问题的文件同时出现在状态监控的待处理事项和文件历史的校验问题中。
5. 在数据仓库搜索、编辑、阅读、汇总和导出。入表不等于已经人工核验，来源状态会继续保留。

## 各页面解决什么问题

| 页面 | 主要用途 |
| --- | --- |
| 状态监控 | 查看活动任务、待选模板、待核对、原件副本问题与失败任务；继续、重试或处理当前页事项 |
| 数据仪表盘 | 查看当前积累、期间变化、模型用量与自定义业务统计；直接前往需复核文件 |
| 文件提取 | 放入文件、选择模板与模型方案，对照原件编辑提取结果并保存 |
| 数据仓库 | 使用同一份事实切换表格或卡片；筛选、修改、分组、导入、合并与导出 |
| 文件历史 | 查找已处理文件与校验问题，查看提取过程、读取范围、内部原件和外部副本状态 |
| 模板 | 定义字段、理解要求、校验规则、默认展示与可选命名；AI 起草、复制、分享和版本恢复 |
| 问知意 | 在授权资料内查找、统计、绘图、解释依据，预览并执行数据与任务操作 |
| 备份 | 导出和恢复业务数据、内部原件；升级或迁移前保留可恢复副本 |
| 接口 | 按需开启 API/MCP 的查询、修改、任务控制与限定目录文件访问 |
| 设置 | 管理模型方案、读取范围、本机服务及应用偏好 |

## v0.4.0 的主要变化

**仪表盘。** 当前存量和所选期间的变化分开计算，支持“全部”时间范围。最多保留四张简单统计，可选记录数、合计、平均值，按类别或日期分组。保存后按当前数据刷新，不调用模型。问知意中符合条件的分析可预览后加入仪表盘。图表支持短促过渡、键盘查看和数据明细，遵循系统减少动态效果设置。

**问知意。** 提取与对话可以使用不同模型。打开历史对话时恢复该对话使用的模型和资料范围；设置中显示下一条消息使用的模型。可选择全部资料或指定表、文件、模板与记录范围，统计数值由程序计算；文件总额不会因多条明细重复相加。资料明确记录了不同币种时不混算，缺失值不充当零。图表保存当时的快照，“按最新数据重新分析”直接在本机复用原统计口径，追加带更新时间的新结果，不调用模型，也不覆盖旧结果。当前授权范围若与原统计口径不兼容，会明确提示。

同一意图的修改合并成一个预览，列出对象和变更前后。默认确认后执行；取消、已执行、过期、被新方案替代和撤销都有对应状态。记录已经变化时会拒绝旧预览，避免覆盖后续修改。“本次委托”仅执行授权内可支持的操作，不开放备份、密钥或操作系统控制。

模板的创建、修改和恢复统一在模板页；问知意可以解释模板，不能替代模板页的样例上传与规则编辑。

**文件命名。** 开启后可二选一：AI 根据内容建议名称，或固定使用“导入日期_模板名_序号”，例如 `2026-09-14_发票_001.jpg`。AI 模式可在额外要求中表达命名偏好，旧模板继续使用 AI 模式；固定模式不请求 AI 起名，同日同模板序号递增，重试沿用已分配名称。名称随提取自动生效，仍可编辑。原上传名和内部原件保留，已导出的外部副本不会被回头改名。

**界面减负。** 状态监控的四个列表保持固定高度，更多任务在列表内滚动。长文件名省略显示，悬浮可看全名，不挤压标签和按钮；副本冲突通过“处理”弹窗改名、换路径、重试或跳过。问知意优先显示最终图表，重复的准备过程可展开查看，文字说明直接呈现；宽表横向滚动，日期和数字保持完整。柱线组合图的轴名称与数值刻度分开显示。

**匹配范围。** 新建和复制的模板默认不参与智能匹配。准备好后，在提取页明确勾选；如果副本用于替代内置模板，同步取消内置模板即可，避免两份相似模板竞争。已有匹配选择保留。

**编辑与反馈。** 模板字段、名称、用途及本机副本目录有未保存编辑时，切换模板或离开页面会提示。按钮悬浮只反馈当前按钮，选中状态清晰但克制；操作确认使用框体，展开与收起有过渡。

## 云端上下文、历史与 reasoning

“上下文预算”在模型方案的高级设置中可见、可修改，它控制知意的请求预算，不是本地模型的加载控件。留空采用自动预算：已知的阿里云 Qwen 3.6 Flash 为 1,000,000 Token；未知远端采用可修改的 32,768，本机默认 8,192。本地预算应与实际加载容量一致，远端预算应与服务的实际能力一致。

旧版远端方案隐含的 8192 会转为自动预算，原数值和旧任务快照保留。旧版未记录数值是界面默认还是接口主动填写，因此无法完美识别旧接口用户手填的 8192；需要继续限制为该值时，可在新版明确填入并保存。新版主动填写的预算保持固定，不随自动推荐变化。

表中有 1000 条或 10000 条记录，也不会整表塞入对话。模型默认得到最多 3 条明细或分组预览，长字段受长度限制；可以指定字段、筛选、排序并按需续读。统计由后端对完整授权范围计算，不把三条预览当作总体。图表引用完整分析快照。

完整对话保存在本机；打开时分页加载最近消息，更早的对话可搜索、翻页或按需回读。知意复用相同方案、相同范围且未变更的原生对话片段；范围、方案或操作状态变化后重建有关上下文。接近预算时压缩历史与工具摘要，完整资料不丢弃。文字通过增量事件直接显示，断线可续传；停止或重启后保留已保存内容，不反复加载整段回答。

云端使用稳定提示前缀，并记录服务实际上报的缓存命中；不承诺每次命中。默认请求关闭 reasoning，服务仍可能自行返回推理片段；内部推理不作为正文展示，用量按服务上报记录。提取正确性、工具执行和数据修改不依赖模型自述。

## 文件、导出与备份的边界

支持 PDF、DOCX、XLSX、常见图片及 TXT/Markdown；复杂版式与嵌入内容的支持有限，完整原件始终可单独下载。上传大小、发送范围、模型上下文与预览范围是不同限制，界面会说明对应阶段。

待核对来源和局部读取信息随支持的 Excel、CSV、JSON 导出保留，包括 MCP 导出。表头与业务文本不会被当作 Excel 公式执行；业务表名包含 `/` 等字符时，导出工作表名会安全转换。

完整备份同时保留业务记录与内部原件。单个备份最多十万个原件，未压缩成员总量上限 100 GiB；磁盘空间不足、清单不完整或校验和不一致时会明确拒绝。外部副本、模型文件和模型密钥不随业务备份搬迁，恢复后需要核对目录与模型连接。

当前仍以 Windows 本地使用为主。大表统计最多接受筛选后的十万行，超出会要求缩小范围，不返回冒充全量的截断结果。模型可能理解错问题，检查实际筛选、数值来源和操作预览，仍是使用流程的一部分。
